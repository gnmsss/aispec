# 安全基线(跨域,优先级仅次于数据库规范)

适用:所有域。各域 baseline 中的安全条款为域内细则,本文件为跨域底线;冲突时以更严格者为准。

## 认证与授权(MUST)

1. 密码存储用 bcrypt/scrypt/Argon2,禁止 MD5/SHA-1;JWT 签名用 RS256/ES256,分布式场景禁止 HS256。
2. Access Token ≤ 30 分钟,Refresh Token ≤ 7 天;连续失败登录 5 次锁定 15 分钟 + CAPTCHA。
3. 敏感操作(改密、支付、权限变更)必须二次验证。
4. 默认拒绝:未明确授权返回 403;非公开 API 必须携带有效 Token;多租户强制租户隔离,用户只能访问自己的数据;服务账号与数据库连接最小权限。

## 数据安全(MUST)

1. 外部通信 TLS 1.2+(推荐 1.3),禁止明文 HTTP 传敏感数据;微服务间推荐 mTLS。
2. 数据分级:绝密(密码、密钥)AES-256 加密、禁止入日志;机密(身份证、银行卡、手机号)加密或脱敏存储、日志脱敏后可记;内部(用户名、邮箱)TLS 传输可存明文。
3. 加密密钥与数据分离存放;数据库备份加密。

## 输入校验(MUST)

1. 所有输入服务端校验,不信任客户端;SQL 一律参数化;HTML 输出转义防 XSS。
2. 文件上传校验类型、大小、内容(文件头,不只扩展名);URL 重定向白名单防开放重定向;JSON/XML 解析限制深度与大小防 DoS。

## API 安全(MUST)

1. 限流:公开 API ≤ 100 次/分/IP,认证 API ≤ 300 次/分/用户(按业务调整并有默认值)。
2. 生产禁止 `Access-Control-Allow-Origin: *`(带凭据时绝对禁止)。
3. 安全响应头:`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY|SAMEORIGIN`、`Strict-Transport-Security`、按需 CSP。
4. 错误响应禁止暴露堆栈、SQL、内部路径。

## 密钥管理(MUST)

1. 代码库禁止硬编码密钥/密码/Token/证书;经环境变量或密钥管理服务(Vault/KMS)注入;`.env` 入 `.gitignore`。
2. CI/CD 密钥走 Secrets;轮换周期 ≤ 90 天,旧密钥 24 小时内失效。

## 审计日志(MUST)

1. 必记事件:登录成功/失败、权限变更、敏感数据访问、管理员操作;字段:时间、用户、操作、资源、来源 IP、结果。
2. 审计日志不可改删,保留 ≥ 180 天;异常行为(批量失败登录、异常 IP、权限提升)告警。

## 依赖安全(MUST)

1. 生产依赖禁止已知高危漏洞版本(CVSS ≥ 7.0);lockfile 入库;CI 必须含漏洞扫描。
2. 修复 SLA:严重(≥ 9.0)24 小时,高危(≥ 7.0)48 小时。

## 事件响应(SHOULD)

1. 安全事件分级 P0~P3,各级明确响应时间与升级路径;事后复盘并更新基线;每季度安全演练。
